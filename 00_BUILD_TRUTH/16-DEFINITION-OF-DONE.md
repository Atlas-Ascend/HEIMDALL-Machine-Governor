# 16 — Definition of Done

HEIMDALL 0.1 is hackathon-ready only when all gates pass:

- [ ] public repository contains OSI-compatible license
- [ ] README provides reproducible setup and run instructions
- [ ] chosen NVIDIA open-source model is currently available and pinned in proof
- [ ] real Nebius runtime call demonstrated
- [ ] working coding-agent scenario repairs a broken repository
- [ ] safe file edit/test commands are allowed
- [ ] destructive or credential action is visibly denied
- [ ] failed verification routes to REPAIR
- [ ] successful verification emits persisted receipt
- [ ] automated tests pass
- [ ] lint passes
- [ ] live demo URL works without paid access
- [ ] demo video is public and <= 3 minutes
- [ ] competition-specific work since Aug 26, 2026 is documented
- [ ] Devpost description names the chosen track and explains Nebius/NVIDIA integration
- [ ] final submission proof is committed

Until every applicable box is evidenced, status is BUILDING — not DONE.
