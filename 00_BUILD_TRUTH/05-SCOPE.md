# 05 — Scope

## In scope for hackathon MVP

- HTTP control-plane API
- execution contract schema
- policy and risk decision engine
- Nebius Token Factory inference adapter
- NVIDIA model selection through configuration
- sandbox/tool adapter contract
- evidence capture schema
- verification result schema
- proof receipt generation
- deterministic adversarial demo
- automated tests and CI
- deployable operator API

## Competition integration requirement

The submitted build must make a real runtime call to Nebius Token Factory or run on Nebius AI Cloud and must use at least one NVIDIA open-source model. The final model ID is pinned only after checking current account availability.

## Product boundary

This repo may reuse architectural principles, but the competition-specific implementation, integrations, demo, tests, and proof artifacts are developed here and tracked explicitly for provenance.
