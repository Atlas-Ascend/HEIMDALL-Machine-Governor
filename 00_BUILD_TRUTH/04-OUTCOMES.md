# 04 — Outcomes

The MVP must produce measurable outcomes rather than agent theater.

- every execution has an immutable identifier
- every requested action resolves to ALLOW, DENY, or REVIEW
- destructive and credential-oriented actions are denied by default
- path and command scope can be expressed in an execution contract
- successful code changes are accompanied by test evidence
- failed verification routes to repair rather than promotion
- final success produces a proof receipt containing objective, policy decisions, evidence references, and verification state
- Nebius/NVIDIA inference is observable as part of the working path
- the demonstration shows one legitimate action allowed and one dangerous action denied

Target demo signal: a judge should be able to distinguish HEIMDALL from an ordinary coding-agent wrapper without reading the source code.
