# 14 — Proof

The repo uses `proof/` as the competition evidence plane.

Required final artifacts:

- CI receipt showing tests/lint pass
- recorded Nebius model ID and provider call timestamp
- model response/request metadata with secrets removed
- sandbox execution trace
- allowed-action policy receipt
- denied-action policy receipt
- patch/diff evidence from the demo repository
- test evidence after repair
- final HEIMDALL receipt
- deployed demo URL
- public source URL
- public YouTube URL under three minutes
- Devpost submission snapshot

Proof is not the same thing as documentation. A claim moves to DONE only when the corresponding artifact exists.
