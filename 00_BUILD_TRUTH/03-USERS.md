# 03 — Users

Primary users are engineering teams deploying autonomous coding or operations agents.

## Personas

1. **Platform engineer** — needs agents to work inside repeatable execution boundaries.
2. **Security engineer** — needs deterministic controls, denial reasons, and audit artifacts.
3. **AI engineer** — needs model-agnostic execution contracts rather than provider-specific prompt rules.
4. **Technical lead** — needs a visible answer to: what did the agent do, why was it allowed, and is the result proven?
5. **Hackathon judge/demo viewer** — must understand the product in seconds through a live permit/deny/repair/verify sequence.

HEIMDALL is not a consumer chatbot. The MVP is an infrastructure product with an operator-facing control plane and a demonstrable coding-agent workflow.
