# 01 — Mission

HEIMDALL exists to make autonomous software agents operationally useful without granting them unbounded machine authority.

The system receives a human or machine objective, compiles that objective into an explicit execution contract, evaluates proposed actions against deterministic policy and risk controls, and only permits actions inside the resulting authorization envelope. Every meaningful action produces evidence. Every claimed completion must survive verification before it may be promoted.

The hackathon product is intentionally narrower than the broader Ghost Atlas estate. It is a standalone, judgeable product focused on one primitive: **governed agent execution**.

Mission success is demonstrated when an NVIDIA-model-backed coding agent can repair a deliberately broken repository through Nebius infrastructure while HEIMDALL visibly permits safe work, denies prohibited actions, records evidence, and issues a final machine-readable proof receipt.

Canonical doctrine: no autonomous action without scope; no completion without evidence; no promotion without verification.
