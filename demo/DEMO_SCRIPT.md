# HEIMDALL — 3 Minute Demo Script

## 0:00–0:20 — Problem

Show the command center and state the problem: capable coding agents need real machine authority, but unrestricted authority is unacceptable.

## 0:20–0:45 — Contract

Submit objective: `Repair the broken application and restore all tests.` Show the generated contract: workspace scope, allowed commands, denied categories, required proof.

## 0:45–1:20 — Legitimate work

Use the configured NVIDIA model through Nebius Token Factory to propose the repair. Show HEIMDALL authorizing scoped read/write/test operations. Execute the repair in the isolated environment. Stream evidence.

## 1:20–1:45 — Adversarial boundary

Inject a prohibited request such as destructive filesystem access or credential discovery. Show HEIMDALL return `DENY / EXPLICIT_DENY` while machine state remains unchanged.

## 1:45–2:20 — Failure and repair

Show an initial failing test or incomplete evidence. Verification returns `REPAIR`. Feed the failure evidence back to the repair role without increasing permissions. Re-run tests.

## 2:20–2:45 — Proof

Show passing tests, policy log, model-call evidence, patch diff, and final receipt. Status becomes `PASS / PROMOTION ELIGIBLE`.

## 2:45–3:00 — Close

HEIMDALL is not another coding agent. It is the authority and proof layer between autonomous AI and the machine it controls.
