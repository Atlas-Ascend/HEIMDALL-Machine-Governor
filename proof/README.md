# Proof Plane

This directory holds evidence generated by the hackathon build and demo.

`runtime/` is ignored because local/runtime receipts can contain machine-specific context. Curated, redacted proof may be promoted into version control after review.

Final expected proof:

- BUILD-MANIFEST.json
- CI receipt/reference
- selected NVIDIA model ID
- Nebius runtime-call evidence
- allow decision receipt
- deny decision receipt
- repair-cycle evidence
- passing test evidence
- final verification receipt
- deployed demo URL
- public demo video URL
- submission snapshot

No secrets, tokens, private repository content, or unrelated machine paths belong in committed proof.
