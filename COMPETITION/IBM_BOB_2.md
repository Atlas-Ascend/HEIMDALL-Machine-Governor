# Competition lane — IBM Bob 2.0 Hackathon

Target: IBM Bob 2.0 Hackathon on lablab.ai, September 25–27, 2026, fully online, solo or team, $10,000 prize pool.

## Provenance boundary

The HEIMDALL governor core in this repository is a pre-event general-purpose infrastructure baseline. It is **not** represented as work built with IBM Bob 2.0. The judged competition implementation must add substantial Bob-specific functionality during the hackathon and disclose this baseline.

Planned event-specific work: use Bob 2.0 with full repository context to inspect an intentionally failing sample project, propose bounded repair actions, emit those actions through HEIMDALL execution contracts, run verification, and compare ungoverned vs governed agentic development. Final submission requires direct evidence that Bob materially participates in the workflow.
